# TikTok 4K HD Enhancer & Auto-Uploader (Dadoott)

Aplikasi pintar untuk meningkatkan kualiti video TikTok menjadi **4K Ultra HD**, tajam, jernih dengan warna dinamik, serta sokongan muat naik terus ke akaun TikTok!

---

## ✨ Ciri-Ciri Utama
- **4K Ultra HD Preset:** Skala 2160x3840 dengan penapis ketajaman unsharp masking lanczos & kontras optimum.
- **2K Crisp & 1080p TikTok Pro:** Kualiti seimbang yang mesra algoritma mampatan (compression) TikTok.
- **Direct Upload / Share:** Sokongan pautan pantas untuk terus buka & muat naik ke TikTok.
- **Pratonton Langsung:** Tonton hasil video sebelum muat naik atau simpan ke galeri.

---

## 🚀 Cara Menjalankan Aplikasi

Jalankan arahan berikut:
```bash
cd ~/tiktok-hd-enhancer
./start.sh
```
Kemudian buka di pelayar:
👉 `http://localhost:8080`
